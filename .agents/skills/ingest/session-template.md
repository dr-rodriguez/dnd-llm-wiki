# Session Note Template

Session notes follow the style of the recent notes (e.g. `wiki/Sessions/2026/2026-09-24.md`, `wiki/Sessions/2026/2026-10-01.md`). Use this skeleton:

```markdown
---
type: session-note
year: YYYY
date: YYYY-MM-DD
tags:
  - CharacterName
  - LocationName
---

# Session: YYYY-MM-DD

<Lead paragraph, 2–4 sentences. Pick up from the previous session ("Picking up from [[Sessions/YYYY/YYYY-MM-DD|YYYY-MM-DD]], ..."), then state the session's main events and where it ends. Bold the key beats and link major entities on first mention.>

*Correction to last session: <only if the raw notes correct an earlier session; also fix that page>.*

## <Scene or Beat Title>
- <One event or fact per bullet, in the order it happened.>
- **Bold the key facts**: decisions, reveals, rolls that mattered, items gained, rewards.
- Point to deeper pages inline: (See [[Lore/Technology#Section|Section]].)

### <Optional Sub-beat>
1. <Numbered lists for goals, options or ordered steps.>

## <Next Scene or Beat Title>
- *Out of character:* <GM clarifications, kept in italics and marked as such.>

## Open Threads
- <Threads this session opened or moved forward: new questions, pending messages, new items, NPCs left unaccounted for.>

## Sources
- [[raw/YYYY/YYYY-MM-DD.md|Original Session Notes]]
```

## Style Rules
- **Headings:** H1 is always `# Session: YYYY-MM-DD`. H2s are short, evocative scene titles in chronological order (`## The Siege Is Over`, `## Teleporting Out`), not generic labels like "Summary" or "Key Information". Use H3 only for a sub-beat inside a scene.
- **Bullets over prose:** Apart from the lead paragraph and short intro lines before a list, the body is bullet points. Keep each bullet to one or two sentences.
- **Bold** names of key items, spells, rewards, reveals and outcomes, not whole sentences.
- **Links:** Link each major character, location, lore entry and quest on first mention using wiki-relative paths with display names (`[[Characters/PC/Maximus Arkelius|Maxim]]`, `[[Locations/Tesselia|Tesselia]]`). Later mentions use the plain short name.
- **Faithfulness:** Report only what the raw notes say. When the notes are ambiguous or contradictory, say so ("the notes call her 'the innkeep'", "the reason is unclear") rather than guessing.
- **Open Threads** and **Sources** are always the last two sections, in that order. Add extra Sources lines when the note also draws on another raw file (e.g. a correction).
- **Open Threads stay local to the session.** List only threads this session opened or moved forward. Don't copy threads forward from earlier notes just because they're still unresolved: the party often moves on and leaves things hanging, and that's normal. An older thread comes back only when this session touches it again. Aim for about 3–6 bullets. Long-running plotlines belong on the relevant quest page, not in every session note.
